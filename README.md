# SkillSwap API
This is a backend project designed to trade knowledge

The core concept is simple: I teach you Node.js, and in exchange, you teach me Technical English. It is a barter system for skills

## Functionality
- User registration and authentication
- Profile management
- Catalog of skills (add skills you have, add skills you want)
- Searching for mentors or partners based on specific skills
- Managing exchange requests (create, accept, reject)

## Tech Stack
- Node.js
- TypeScript
- NestJS
- Sequelize 
- Docker
